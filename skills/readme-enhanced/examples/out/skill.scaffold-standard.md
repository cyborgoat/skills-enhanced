## Installation

```bash
git clone https://github.com/acme/skill.git
cd skill
pip install -r requirements.txt
```

Then make the skill available to Claude Code by copying the folder into your skills directory:

```bash
cp -r csv-cleaner ~/.claude/skills/
```

## Usage

Ask Claude in natural language, or invoke the skill directly:

```text
/csv-cleaner <what you want>
```
